# 🛍️ Istanbul Shopping Mall — Customer Data Analysis
**PRDA-05 | Project Team ID: PTID-CDA-FEB-26-1308**

## 📌 Project Overview
Analysis of 99,457 customer transactions from 10 Istanbul 
shopping malls between 2021–2023.
Total Revenue: ₺251.5 Million

## 🛠️ Tools Used
- Python (Pandas, Matplotlib)
- Power BI Desktop
- Microsoft PowerPoint

## 🔍 Key Findings
- Female customers = 59.8% of shoppers & ₺150.2M revenue
- 55+ age group = highest spenders at ₺67.1M
- Clothing = 45.3% of all revenue (₺114M)
- Cash = dominant payment method at 44.69%
- Mall of Istanbul = top mall at ₺50.9M

1. KPI Summary — ₺251.5M revenue, 99K orders

3. Age Group Analysis — 55+ leads at ₺67M
